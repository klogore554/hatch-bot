# Хаб-бот · Rust

Это ветка `rust` — тот же бот, что и в [`main`](https://github.com/klogore554/hatch-bot/tree/main), но на Rust. Ридми в ветках разные: там про Python, здесь про Rust. Логика, кнопки, оффер и `CONTENT.md` одинаковые.

## Зачем Rust

- холодный старт почти мгновенный;
- один бинарник, меньше зависимостей на хосте;
- нет GIL и интерпретатора — отклик ровнее на слабом железе;
- меньше памяти при росте числа пользователей.

Честно: основная задержка ответа — это сеть до Telegram. Но на дешёвом хостинге Rust всё равно приятнее.

## Python или Rust

| | `rust` (эта ветка) | `main` (Python) |
|---|---|---|
| Язык | Rust 1.75+ | Python 3.10+ |
| Запуск | `cargo run --release` | `python bot.py` |
| Данные | JSON, `habit.json` | SQLite, `habit.db` |
| Старт | почти мгновенно | секунды |
| Память | меньше | больше |
| Править логику | нужно знать Rust | легко, понятный синтаксис |
| Выбрать, если | важен отклик и расход ресурсов | хочешь быстро переделать под себя |

Обе ветки работают с Lava и используют один и тот же `CONTENT.md`.

## Что умеет

- `/start` с метками `?start=vid1`, `?start=ref123`;
- привычки, серии, `/remind 09:00` по Москве;
- групповой `/challenge` и рейтинг `/top`;
- кнопки «📄 Документы»: оферта, возврат, политика данных;
- `/subscribe` → Lava recurrent → ссылка на оплату;
- проверка оплаты раз в минуту и автопродление Pro;
- предупреждение за 3 дня до конца подписки;
- `/health` для проверки деплоя.

Всё основное — кнопками. Команды тоже работают.

## Запуск локально

Нужен Rust 1.75+ и токен от `@BotFather`.

```powershell
git clone <твой-форк>.git
cd habit-bot
git checkout rust
$env:BOT_TOKEN = "токен_от_botfather"
cargo run
```

Без ключей Lava бот поднимется. `/subscribe` скажет, что оплата не настроена, — это нормально.

Релизная сборка:

```powershell
cargo build --release
.\target\release\habit-bot-rs.exe
```

Проверка логики: `cargo test` — два теста на привычки, рефералку, оплату и челлендж.

## Переменные окружения

`.env` не используется, всё задаётся на хосте.

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен из `@BotFather` |
| `DB_PATH` | путь к JSON-базе, по умолчанию `habit.json` |
| `LAVA_SHOP_ID` | UUID магазина Lava |
| `LAVA_SECRET_KEY` | секретный ключ проекта |
| `LAVA_PRODUCT_ID` | UUID рекуррентного продукта |
| `LEGAL_NAME`, `LEGAL_INN` | реквизиты продавца в оферте |
| `SUPPORT_EMAIL`, `SUPPORT_TG` | контакты поддержки |
| `PORT` | порт health-сервера, по умолчанию 8000 |
| `HEALTH_SERVER` | `1` — включить health-сервер |

Без `LEGAL_*` и `SUPPORT_*` документы откроются, но без реквизитов. Для модерации заполни.

## Деплой

Railway сам определяет Rust по `Cargo.toml`. В настройках: Branch — `rust`, Start Command — `cargo run --release` (в `Procfile` уже так).

Добавь Volume на `/data` и задай `DB_PATH=/data/habit.json`, иначе база потеряется при redeploy. Проверка: `GET /health` должен вернуть `{"ok":true}`.

## Структура

- `src/main.rs` — запуск, polling, планировщик, health-сервер;
- `src/handlers.rs` — команды и кнопки;
- `src/store.rs` — JSON-хранилище и тесты;
- `src/lava.rs` — платёжный клиент с HMAC-подписью;
- `src/legal.rs` — тексты документов;
- `src/telegram.rs` — обёртка над Bot API;
- `CONTENT.md` — ролики и deep-link, общий для веток.

## Что учесть при форке

1. Поменяй `PRESETS` в `src/handlers.rs` под свои привычки.
2. В `src/legal.rs` поправь тексты документов. Реальные реквизиты не пиши в файл — они приходят из переменных окружения.
3. Создай свой рекуррентный продукт в Lava и задай три переменные `LAVA_*`.
4. Цена 299 ₽ зашита в текстах — поменяй её и в Lava, и здесь, и в `CONTENT.md`.
5. Метки `vid1…vid7` описаны в `CONTENT.md`.

Вывод денег делается в личном кабинете платёжного сервиса. Отдельного скрипта нет.

## Ограничения

- JSON-файл подходит для небольшого проекта. На тысячи пользователей лучше Postgres.
- Время везде московское. Другая зона — правка `msk()` в `src/store.rs`.
- Статусы оплаты Lava стоит проверить маленьким реальным платежом до рекламы.
- Если после цикла роликов нет продаж — чини оффер и трафик, а не код.

Форкай и переделывай под свою идею.
