# 7 роликов: нейтральные скрипты

Скрипты не содержат персональных данных. Вместо имени бота везде плейсхолдер `<bot_username>` — замени его один раз перед публикацией.

## Ссылки для отслеживания

Одна и та же страница Taplink в профиле, но разные кнопки ведут на разные deep-link:

| Метка | Назначение | Ссылка |
|---|---|---|
| `vid1` | Напоминания | `https://t.me/<bot_username>?start=vid1` |
| `vid2` | Групповой челлендж | `https://t.me/<bot_username>?start=vid2` |
| `vid3` | Реферальная механика | `https://t.me/<bot_username>?start=vid3` |
| `vid4` | Короткие тренировки | `https://t.me/<bot_username>?start=vid4` |
| `vid5` | Вода | `https://t.me/<bot_username>?start=vid5` |
| `vid6` | Серии | `https://t.me/<bot_username>?start=vid6` |
| `vid7` | Pro | `https://t.me/<bot_username>?start=vid7` |

Бот сохраняет метку при `/start`, поэтому видно, какая тема привлекла пользователя.

## 1. Напоминания

**Хук:** «Забываешь о привычке? Бот напомнит и поставит галочку».

**Экран:** телефон, утреннее уведомление, нажатие ✅.

**Текст за кадром:**
> Напоминание приходит в заданное время. Одно нажатие продолжает серию, пропуск обнуляет её. Привычка формируется без героизма — главное не прервать цепочку.

**Подпись:** Напоминания для привычек — ссылка в профиле.

**Кнопка Taplink:** «Забрать бота» → `vid1`

## 2. Групповой челлендж

**Хук:** «Челлендж в чате: кто сегодня сделал?»

**Экран:** групповой чат, команда `/challenge`, рейтинг участников.

**Текст за кадром:**
> В группе запускается челлендж на 7 дней. Каждый день участники отмечаются, бот показывает рейтинг. Видя отстающих, участники сами приглашают новых.

**Подпись:** Общий челлендж — ссылка в профиле.

**Кнопка Taplink:** «Войти в челлендж» → `vid2`

## 3. Реферальная механика

**Хук:** «Два приглашения — три дня Pro».

**Экран:** команда `/referral`, ссылка, две отметки о запуске.

**Текст за кадром:**
> В боте есть реферальная ссылка. Два пользователя запустили бота — и пригласивший, и новые участники получили по три дня Pro. Механика работает без промокодов и ручной проверки.

**Подпись:** Своя ссылка — в команде `/referral`.

**Кнопка Taplink:** «Получить ссылку» → `vid3`

## Одна ссылка в профиле TikTok

В TikTok можно оставить **одну** ссылку. Это нормально: она ведёт на страницу Taplink, а уже на ней находятся кнопки.

Рекомендация:

- оставь в профиле одну ссылку на Taplink;
- на странице Taplink сделай 3–7 кнопок с deep-link из таблицы выше;
- в каждом ролике говори, какую кнопку выбрать: например, «жми “Войти в челлендж”»;
- в Taplink включи статистику переходов по кнопкам — так будет видно, какая тема работает.

Точная привязка «конкретный ролик → конкретный переход» при одной ссылке в профиле невозможна без ручного шага. Достаточно привязки по теме/кнопке.
