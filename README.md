# Хаб-бот

Телеграм-бот с привычками, стриками, групповым челленджем, рефералкой и подпиской через Lava.

**Фишка не в одиночной напоминалке, а в сарафанке:**

- `/referral` — пригласил 2 друзей → оба получили +3 дня Pro;
- `/challenge` в группе — общий рейтинг на 7 дней, участники сами зовут друзей;
- челлендж может начать любой участник, бот не требует от тебя общения с покупателями.

## Что уже есть

- `/start` с deep-link: `?start=vid1` / `?start=ref123` — видно, откуда пришёл юзер и кто пригласил;
- привычки из пресетов + свои, лимит 1 в Free и без лимита в Pro;
- ✅-отметки, стрики, `/remind 09:00` (МСК);
- групповой челлендж, кнопка «Я сделал», рейтинг `/top`;
- `/subscribe` → email → Lava recurrent → ссылка на оплату;
- раз в минуту проверяется статус подписки и продлевается Pro на 30 дней;
- предупреждение за 3 дня до конца Pro;
- `HEALTH_SERVER=1` поднимает `/health` для Railway.

## Что нужно от тебя

### Модерация платёжного сервиса

Персональные данные и документы передаются **напрямую в личный кабинет платёжного сервиса** — их нет в этом репозитории и они не попадают в код.

### Ключи

- `BOT_TOKEN` — от `@BotFather`;
- `LAVA_SHOP_ID` — UUID магазина в Lava;
- `LAVA_SECRET_KEY` — секретный ключ проекта;
- `LAVA_PRODUCT_ID` — UUID созданного рекуррентного продукта;
- `DB_PATH` — путь к базе, на Railway лучше `/data/habit.db`;
- `PORT` — Railway задаёт сам;
- `HEALTH_SERVER=1`.

**Файл `.env` не создаётся.** Все переменные задаются на хосте/Railway.

## Локальный запуск

```powershell
cd D:\project\habit-bot
python -m pip install -r requirements.txt
$env:BOT_TOKEN="токен_от_botfather"
python bot.py
```

Без ключей Lava бот всё равно запустится, но `/subscribe` будет ругаться — это нормально.

## Railway

1. Новый проект → Deploy from GitHub repo (папка `habit-bot`).
2. Settings → Variables — добавь переменные выше.
3. Settings → Volumes → добавь Volume, смонтируй на `/data`.
4. Start Command: `python bot.py`.
5. Проверка: `GET /health` должен вернуть `{"ok":true}`.

 Railway подходит Lava как коммерческий хостинг.

## Lava

В личном кабинете:

1. Создать проект и пройти модерацию.
2. Создать **рекуррентный продукт** 299 ₽ / 1 месяц.
3. Взять `shopId`, секретный ключ и `productId`.

Webhook не обязателен: бот сам опрашивает `/business/recurrent/subscription/status` раз в минуту.  
Точные значения статусов (`activated` и т.д.) стоит сверить с поддержкой Lava — в коде есть эвристика `lava.looks_paid()`.

## Taplink и TikTok

Открой `CONTENT.md` — там 7 готовых скриптов на неделю и три кнопки для Taplink.

План под твой режим:

1. Записать все 7 роликов **за один день**.
2. Залить их в TikTok через планировщик.
3. Неделю вообще не прикасаться к контенту.
4. Смотреть в `/start vid1…vid7`, какой ролик дал запуски.

Ориентир на 1 000 подписчиков: 7 роликов × ~300–500 просмотров ≈ 2–3.5k просмотров, 40–150 кликов в Taplink, 15–80 запусков бота, 1–5 первых платящих. Этого хватает, чтобы проверить идею, но не чтобы разбогатеть.

## Важно

- Если после 7 роликов нет ни одной продажи — проблема не в коде, а в оффере/аудитории. Меняем идею, а не дописываем бота.
- Lava выводит деньги на карту или кошелёк; эквайринг Т-Банка и крипта не нужны.
- Чеки по операциям: уточни у платёжного сервиса, кто их формирует. Храни их для банка.
- 115-ФЗ/Альфу с доп-проверками как основную приёмную площадку не используй. С Lava деньги приходят не от покупателей напрямую, а выплатой от платёжного сервиса.
